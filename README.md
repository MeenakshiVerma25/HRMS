# HRMS
Human Resource Management System (HRMS) built using PHP, MySQL, Bootstrap, JavaScript, jQuery, and DataTables. Features include employee management, attendance, payroll, leave management, recruitment, onboarding, loans &amp; advances, and role-based dashboards.
# Features
- Employee Management
- Role-Based Dashboard
- Attendance Management
- Leave Management
- Payroll Management
- Recruitment Module
- Onboarding Module
- Loans and Advances
- Reports and Analytics
- DataTables Integration
- SweetAlert Notifications
# Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- DataTables
- SweetAlert2
